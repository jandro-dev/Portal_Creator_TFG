## Portal Creator – Trabajo de Fin de Grado

Plataforma web para la creación y gestión de portales de contenido, desarrollada como parte de un **Trabajo de Fin de Grado (TFG)**. La aplicación permite a cada usuario crear su propio perfil, organizar enlaces en diferentes categorías y personalizar la apariencia visual de su portal.

### Tecnologías utilizadas

- **Angular**
- **Springboot**
- **TypeScript**
- **Bootstrap**

### Funcionalidades principales

- **Creación de perfiles**: cada usuario puede crear y gestionar su propio portal de contenido.
- **Organización por categorías**: clasificación de los enlaces mediante categorías personalizadas.
- **Administración de enlaces**: creación, edición y eliminación de enlaces asociados a cada categoría.
- **Gestión de información**: los datos se gestionan mediante una API.
- **Diseño responsive**: adaptación a dispositivos móviles, tablets y ordenadores.
- **Interfaz sencilla e intuitiva**: navegación clara que facilita la creación y consulta del contenido.
